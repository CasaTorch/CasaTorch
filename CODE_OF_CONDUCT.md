# Code of Conduct

CasaTorch follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short:

- **Be kind and assume good intent.** Many people here are setting up their first home dashboard. Questions are
  welcome; there are no silly ones.
- **Keep it about the work.** Critique code, ideas and docs - never people.
- **No harassment of any kind:** no insults, personal attacks, sexualized language or imagery, trolling, or
  unwelcome attention, in public or in private.
- **Respect privacy.** Never post someone else's personal information - and never your own home's: addresses, IP
  and MAC addresses, camera pictures, tokens. Support files mask these; check before you post.

This applies in the repository (issues, pull requests, discussions), in CasaTorch's community spaces, and anywhere
someone represents the project.

## Reporting

[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
